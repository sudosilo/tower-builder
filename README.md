Tower Builder

Tower Builder is a small engineering game. It is for anyone who likes to build and test structures.

You place beams of steel, wood, or reinforced concrete between grid nodes while staying within a budget. A test runs a wind test and then an earthquake against the target height. Budget, spent, target height, score, and level show on screen.
